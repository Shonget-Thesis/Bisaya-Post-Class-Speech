# Face Modality

This folder is reserved for facial-feature outputs derived from the participant videos.

No face feature dataset has been generated yet. Do not place raw videos here or describe this modality as complete until:

1. Video processing is explicitly covered by participant consent and institutional approval.
2. A documented face-feature extraction method has been selected.
3. Every output row has been matched to one pseudonymous participant code.
4. Detection quality, missing faces, and failed videos have been reported.

Expected future outputs may include a facial-feature CSV, extraction-quality report, feature definitions, and analysis figures. Raw recordings remain in `Videos/` and should not be uploaded unless sharing is authorized.
